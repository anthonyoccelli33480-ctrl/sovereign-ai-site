Vos documents, chez vous

Votre validation, toujours

Chaque action engageante attend votre accord. C'est inscrit dans le moteur, pas dans une promesse.

Sérieux vérifiable

Connexion Gmail / Outlook aux standards de sécurité actuels, sauvegardes chiffrées, 40 tests automatisés.

Pour le lecteur curieux — sous le capot

Recherche documentaire locale en SQLite FTS5 (mots-clés pondérés), avec embeddings optionnels servis par Ollama — donc toujours en local. OAuth PKCE pour Gmail et Microsoft. Les données venant de l'extérieur (pages web, mails entrants) sont encadrées par des marqueurs de défiance et filtrées contre l'injection de prompt avant d'approcher le modèle. Sauvegardes chiffrées (Fernet). Le tout tourne sur 127.0.0.1 — votre machine, point.
